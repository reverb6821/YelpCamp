# YelpCamp
YelpCamp is a Node.js web application with RESTful routing project from the Udemy course - The Web Developer Bootcamp by Colt Steele
<hr>
<a href="https://yelpcamp-ap.herokuapp.com/">Live Demo</a>
<hr>
<b>Features</b>
<ul><b>Authentication:</b>
  <li>User login with username and password (You can create one, or just log in with Username: user Pass: 1234)</li>
</ul>
<ul><b>Authorization:</b>
  <li>One cannot manage posts and view user profile without being authenticated</li>
  <li>One cannot edit or delete posts and comments created by other users</li>
</ul>
<ul><b>Manage campground posts with basic functionalities:</b>
  <li>Create, edit and delete posts and comments</li>
  <li>Upload campground photos</li>
  <li>Display campground location on Google Maps [TEMPRARILY DISABLED]</li>
</ul>
